# Quick Add prototype

Interactive prototype for CMPM 290 Project 2 (Trustworthy Online Experiments, UC Santa Cruz).

It compares two versions of a product listing on a mobile web store:

- **A (control):** tap a card, open the detail page, choose color and size, then Add to cart.
- **B (Quick Add):** tap "+" on a card, choose color and size in a bottom sheet, then Add to cart.

Use the switch at the top of the page to move between A and B.

This is a student design prototype. It is not affiliated with or endorsed by UNIQLO. It is not a real store and nothing can be purchased. Product photos are screenshots used for coursework only.
